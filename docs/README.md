## Матриця нефункціональних вимог (NFRs) — витяг

| ID | Категорія | Цільова метрика |
|---|---|---|
| NFR-P1 | Продуктивність | p95 latency критичних API ≤ 200 мс при 500 RPS |
| NFR-P2 | Реалтайм | Телеметрія на мапі ≤ 1.5 с; оновлення ≥ 1 Гц |
| NFR-P3 | Масштабованість | Прийом ≥ 5000 пов./с; ≥ 300 одночасних рейсів |
| NFR-P4 | Планувальник | Побудова маршрутів ≤ 3 с (p95); перерахунок ≤ 5 с |
| NFR-S1 | Автентифікація | OAuth 2.0 / OIDC, підписані JWT (RS256), TTL ≤ 15 хв |
| NFR-S3 | Шифрування | TLS 1.3; шифрування PII at-rest (AES-256) |
| NFR-S4 | Комплаєнс | OWASP API Security Top-10; SAST у CI, 0 critical |
| NFR-R1 | Доступність | Трекінг ≥ 99.9%; деградація planner не спиняє трекінг |
| NFR-R2 | Відмовостійкість | retry+backoff, circuit breaker, timeout ≤ 2 с, DLQ |
| NFR-R4 | Надійність даних | Kafka replication factor ≥ 3; RPO ≤ 5 хв |

> Повна NFR-матриця (17 вимог) — у підрозділі 1.5 Розділу 1 та на сторінці PKM
> «Постановка задачі та формування вимог».
